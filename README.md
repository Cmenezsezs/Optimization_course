# 📚 Introdução à Otimização em Python

**Curso de Matemática e Ciência de Dados | UFPB (Universidade Federal da Paraíba)**

Este repositório contém os materiais, códigos e roteiros de estudo do curso de **Introdução à Otimização em Python**, ministrado para o bacharelado em Matemática e Ciência de Dados na UFPB. O objetivo do curso é capacitar os alunos a modelar matematicamente problemas de negócios e ciências, resolvendo-os computacionalmente através de técnicas de otimização linear, não linear e convexa.

---

## 🎯 Sobre o Curso

A otimização é o motor por trás de decisões eficientes em Ciência de Dados, desde a alocação de recursos até o treinamento de modelos de Machine Learning. Durante este curso, exploramos desde os fundamentos do cálculo diferencial para otimização até a resolução de problemas complexos de programação linear inteira mista (MILP) utilizando as principais bibliotecas do ecossistema Python.

---

## 🛠️ Ferramentas Utilizadas

* **Python:** Linguagem base do curso.
* **SymPy:** Para cálculo simbólico, derivadas parciais e otimização analítica.
* **SciPy:** Para otimização numérica (com e sem restrições) e busca de ótimos globais.
* **PuLP:** Para modelagem e resolução de problemas de Programação Linear e MILP.

## 🚀 Como usar este repositório

1. Clone o repositório para sua máquina local:
`git clone [https://github.com/seu-usuario/otimizacao-python-ufpb.git](https://github.com/seu-usuario/otimizacao-python-ufpb.git)`
2. Instale as dependências necessárias listadas no arquivo de requisitos:
`pip install -r requirements.txt`
3. Navegue pelas pastas dos módulos para acessar os Jupyter Notebooks de cada aula e listas de exercícios correspondentes.
